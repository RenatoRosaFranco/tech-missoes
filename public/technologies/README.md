# Technology icons

Unmodified SVGs downloaded from Dashboard Icons (Homarr Labs):
https://dashboardicons.com/icons
https://github.com/homarr-labs/dashboard-icons

Source: https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/{name}.svg
Names: typescript, reactjs, nodejs, python, pytorch, arduino, raspberry-pi,
git, github, github-light, docker, ruby, ruby-on-rails.

The upstream LICENSE is included in this directory. Brand names and logos
belong to their respective owners.

`monochrome/` contains modified luminance masks derived from the source SVGs:
colored ink becomes white and white negative-space details become black.
CSS supplies the light gray and selected red colors. Original SVGs remain intact.
